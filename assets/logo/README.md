# RantaiClaw logo

| File | Use on |
|---|---|
| `rantaiclaw-wordmark-light.svg` | light backgrounds (navy text) |
| `rantaiclaw-wordmark-dark.svg` | dark backgrounds (white text) |
| `rantaiclaw-icon-light.svg` | light backgrounds, square spaces such as an avatar |
| `rantaiclaw-icon-dark.svg` | dark backgrounds, square spaces |

The root `README.md` picks the wordmark that matches the reader's GitHub theme.
The terminal UI draws the same bracket mark as text, from `src/tui/assets/mascot_ascii.txt`.
